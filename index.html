スラコロ専用ギフト
期待値計算ツール

スラコロ専用ギフトで獲得できるGP・オッズ・アイテムの期待値の目安や確率を確認できます。

贈る個数から計算

贈る予定のスラコロ専用ギフトの個数を入力してください。

GP期待値 0 GP
オッズ期待値 0 Lv.Up
限界突破ぶる太くん人形期待値 0 個
エモモの宝玉期待値 0 個
獲得メダル期待値 0 メダル
消費無償コイン 0
消費有償コイン 0

使用コインから計算

使用できる無償コイン・有償コインの上限額を入力してください。

GP期待値 0 GP
オッズ期待値 0 Lv.Up
限界突破ぶる太くん人形期待値 0 個
エモモの宝玉期待値 0 個
獲得メダル期待値 0 メダル
ギフト 贈る個数 消費コイン

※ 有償コインは豪華な宝箱に使用する想定です。
※ コインあたりの期待値が高いギフト（10連 普通の宝箱 > 普通の宝箱 / 10連 豪華な宝箱 > 豪華な宝箱）から優先して使い切る組み合わせを想定して表示しています。

目標GPから計算

目標のGPを貯めるために必要なギフト数の目安を計算します。

GP貯めるのに必要な個数の目安 0 個
GP貯めるのに必要なコイン数の目安 0
GP期待値 0 GP
ギフト 必要個数の目安 必要コイン

※ 確率に基づく期待値です。実際に貯まるGPは各種宝箱の中身によって前後するため、目標達成を保証する数値ではありません。

目標オッズから計算

目標のオッズLv.を上げるために必要なギフト数の目安を計算します。

オッズLv.0Upに必要な個数の目安 0 個
オッズLv.0Upに必要なコイン数の目安 0
オッズ期待値 0 Lv.Up
ギフト 必要個数の目安 必要コイン

※ 確率に基づく期待値です。実際に上がるオッズは各種宝箱の中身によって前後するため、目標達成を保証する数値ではありません。

目標の限界突破ぶる太くん人形数から計算

目標の限界突破ぶる太くん人形の個数を獲得するために必要なギフト数の目安を計算します。

限界突破ぶる太くん人形0個獲得に必要な個数の目安 0 個
限界突破ぶる太くん人形0個獲得に必要なコイン数の目安 0
限界突破ぶる太くん人形期待値 0 個
ギフト 必要個数の目安 必要コイン

※ 確率に基づく期待値です。実際に獲得できる限界突破ぶる太くん人形の数は各種宝箱の中身によって前後するため、目標達成を保証する数値ではありません。
